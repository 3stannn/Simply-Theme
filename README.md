# Simply Theme

A minimal VS Code theme with a `#171717` editor background, `#F5F5F5` text, blue interface accents, and soft syntax colors.

## Preview

1. Open this folder in VS Code.
2. Press **F5** to launch the Extension Development Host.
3. In the new window, open **Preferences: Color Theme** from the Command Palette and choose **Simply Dark**.
4. The included `samples/preview.ts` gives you a syntax preview.

Edit `themes/simply-dark-color-theme.json` while the preview window is open to see your color changes.

## Customize

- `colors` controls the editor, sidebar, tabs, terminal, and other interface surfaces.
- `tokenColors` controls syntax highlighting.
- `semanticTokenColors` controls language-aware highlighting.
- `package.json` defines the theme's name and extension details.

This is a local starter theme. Set your own publisher identifier and publishing metadata before packaging it for the Marketplace.
